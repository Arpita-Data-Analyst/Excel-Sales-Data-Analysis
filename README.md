# Excel-Sales-Data-Analysis

## Project Overview
This project focuses on analyzing sales data using Microsoft Excel to understand business performance and identify useful insights.

## Tools Used
- Microsoft Excel 365

## Project Workbook
The workbook contains 8 sheets covering different aspects of sales data analysis.

## Key Skills
- Data Cleaning
- Excel Formulas
- Sorting and Filtering
- Data Analysis
- Data Organization

## Project Objectives
- Analyze sales performance.
- Organize and clean datasets.
- Calculate important sales metrics.
- Identify useful business insights.
